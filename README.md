# Sistema de Asistencias para Escuela Dominical

Sistema web desarrollado para el control y gestión de asistencias de alumnos en una escuela dominical, permitiendo un registro organizado y eficiente de la información.

## 🛠️ Tecnologías utilizadas
- JavaScript
- Node.js
- HTML5
- CSS3
- Base de datos
- Git y GitHub

## Funcionalidades
- Registro de alumnos
- Control de asistencias
- Gestión de información académica
- Organización y consulta de datos
- Interfaz sencilla y funcional

## Estructura del proyecto
- `backend/` – Lógica del servidor
- `interfaz/` – Interfaz de usuario
- `imagenes/` – Recursos visuales
- Configuración y dependencias del proyecto

## Objetivo del proyecto
Desarrollar un sistema que facilite el control de asistencias en instituciones educativas, optimizando la organización y el acceso a la información.
